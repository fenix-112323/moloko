🌱 Кокосовое молоко

Альтернатива

Другие названия: сантан, кокосовые сливки

Для готовки (карри, десерты).

Кокосовое молоко — это не сок из ореха. Его делают из тёртой мякоти зрелого кокоса: мякоть заливают водой и отжимают. Прозрачная жидкость внутри ореха называется иначе — кокосовая вода. Самая густая и жирная часть — кокосовые сливки. Обычное кокосовое молоко для готовки содержит до 20% жира.

Кокосовое молоко — основа многих кухонь Юго-Восточной Азии, Южной Азии, Океании и Восточной Африки. На нём готовят карри, супы, рис и сладкие десерты. Именно поэтому в справочнике оно связано прежде всего с кухней. Консервированное кокосовое молоко для готовки не предназначено для питья. Для питья продают другой продукт — разбавленный кокосовый напиток в пакетах, который заменяет молоко в кофе или каше.

Большая часть жира в кокосовом молоке — насыщенные жиры. Многие организации здоровья советуют их ограничивать, потому что они могут повышать холестерин в крови. Лактозы и молочного белка в кокосовом молоке нет. В Евросоюзе слово «молоко» разрешено только для молока животных, но для кокосового молока сделано исключение.

Частые вопросы

Из чего делают кокосовое молоко?

Из тёртой мякоти зрелого кокоса, которую отжимают с водой. Кокосовая вода — это другая жидкость из ореха.

Можно ли пить кокосовое молоко из банки?

Консервированное кокосовое молоко сделано для готовки и очень жирное. Для питья выпускают разбавленные кокосовые напитки.
